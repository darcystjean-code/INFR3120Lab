All of the code I have used has been written by myself using examples from lecture and tutorial slides as a reference to guide my websites design.

I used screen width thresholds of 980px, 481px, and 480px to determine the different stylesheets used for different viewports as they are the current standard.

The color scheme i used was created using the adobe color palette tool https://color.adobe.com/create/color-wheel?color-palette=005A8C%2C8C6100%2C8C3600%2C80D2FF%2CFFD880&color-palette-name=My+Color+Theme

I used a linear gradient for the background on the contact me page and an angled gradient for the backgrounds on the project boxes on the projects page.
